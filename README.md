# Milkdromeda Studios

The portfolio website for Milkdromeda Studios.

## Website

The site is a lightweight, responsive static website built with plain HTML, CSS and JavaScript. It has no build step, package manager, framework dependency or external runtime requirements.

## Deploying

This repository is configured as a GitHub Pages site. Publish the repository root from the `develop` branch (or the branch configured in **Settings → Pages**).

## Updating projects

Edit the project cards in `index.html`. Each card uses a `data-category` attribute for filtering and links directly to its project repository.
